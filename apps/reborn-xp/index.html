About Reborn XP

Reborn XP is our flagship experience and the most accurate Windows XP simulator online. It is a meticulously crafted, high-fidelity simulation that replicates the real operating system with true 1:1 pixel-perfect accuracy in every single detail. No other project has ever come this close.

Every sound, animation, theme, and app (from the Start Menu to the file system) is recreated exactly as it was in the early 2000s. It runs instantly and smoothly in your browser, no installation required.

What's Included in the Experience:

  • A Complete Desktop Experience: An interactive desktop with the exact Start Menu, taskbar, system tray, window animations, and draggable icons.
  • Every Official Theme: Perfectly recreated themes including Luna (Blue, Silver, Olive), Royale (Blue, Noir), Zune, Watercolor, and the complete Classic set.
  • All Original Classic Apps: Use 1:1 recreations of Paint, Notepad, WordPad, Calculator, Minesweeper, Solitaire, 3D Pinball, Windows Media Player (with skins), Command Prompt, and more.
  • Original MSN Messenger: Chat with working bots, send nudges and winks, and use the full set of original emoticons.
  • Persistent Virtual File System: Features C:, D:, and E: drives. Upload your own photos, music, and documents by dragging them onto the desktop, and they will stay saved privately in your browser.
  • Built-in App Market: Install extra apps and games directly from inside XP, including fan-favorites like BonziBuddy, a working Flash Player, and BootSkin XP.
  • Multiple User Accounts: Create and switch between different user accounts, each with its own password and settings, just like the real OS.

Whether you want to relive the golden era of computing, run retro games, prank your friends, or just enjoy that pure early-2000s desktop feeling, Reborn XP is the most complete and authentic Windows XP experience available anywhere.

Frequently Asked Questions

Reborn XP is a highly advanced simulation built from scratch with modern web technologies. It is designed to perfectly mimic the experience of using Windows XP, but it is not the actual operating system and cannot run traditional Windows desktop programs (.exe files). However, you can install new apps and games specifically made for Reborn XP through the built-in App Market.

It's easy! Just like the original, you can find all the classic games by going to the Start Menu > All Programs > Games. Click on any game, such as 3D Space Cadet Pinball, Solitaire, Spider Solitaire, or Minesweeper, to launch it instantly and start playing.

You can fully customize the look and feel of your desktop. Right-click anywhere on the Desktop and select Properties. In the new window, go to the Themes tab and use the dropdown menu to select from iconic themes like Luna (Blue, Olive, Silver), Royale, Zune, and more. For even more options, go to the Appearance tab.

Your data is completely private and secure because it never leaves your computer. Everything you create inside Reborn XP is stored locally in your web browser's storage (a technology called IndexedDB). We do not have any access to your virtual files. Clearing your browser's site data is the only way to erase your virtual hard drive.

The easiest way is to simply drag and drop files from your real computer's desktop directly onto the Reborn XP desktop. You can also right-click on the virtual desktop or in an Explorer window, select New, and then Upload from Computer....

They are designed just like a real PC. The C: (System Drive) holds the core OS files and is reset during updates, except for user's documents and desktop files. The D: (Persistent Storage Drive) is your personal space; files saved here will never be deleted by an update. The E: (Goodies CD Drive) is a rewriteable drive with fun extras, like music, videos, and prank programs.
